Antes de generar pagos, debes contar con las credenciales proporcionadas por tu banco:

Código de comercio (FUC), el número de terminal, la moneda (por ejemplo,
978 para EUR) y la clave secreta de encriptación (proporcionada en formato Base64).

Estas credenciales se usan para autenticarse en Redsys mediante
la generación de firmas digitales de las peticiones.

https://pagosonline.redsys.es/desarrolladores-inicio/integrate-con-nosotros/tarjetas-y-entornos-de-prueba/

Cuando rellenes estos datos, recibirás en tu bandeja de correo las instrucciones detalladas para utilizar tu cuenta de prueba. Recuerda que esta cuenta sólo estará disponible durante 7 días, y que el enlace que se adjunta en tu correo, sólo permite acceder directamente una vez; después, deberás usar el usuario y la contraseña que fijaste durante el registro. El correo que recibas, tendrá un aspecto similar al que se muestra, y desde ahí, podrás acceder directamente al Portal de Administración del TPV Virtual para administrar tu Terminal de pruebas.
